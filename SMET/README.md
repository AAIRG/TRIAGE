# SMET (mapping CTI reports and CVE to ATT&CK)
SMET : Semantic Mapping of CVE to ATT&amp;CK and its Application to Cybersecurity <br>
https://link.springer.com/chapter/10.1007/978-3-031-37586-6_15

ATT&CK BERT for semantically meaningful cybersecurity text embedding: https://huggingface.co/basel/ATTACK-BERT

Original Git Repository: https://github.com/basel-a/SMET/tree/main

## Organization

- `SMET.py`: Main module implementing the mapping from text to ATT&CK using embeddings and a trained classifier.
- `run_smet.py`: Script to run the SMET model on experiment data (train/test splits), producing 
  ranked ATT&CK predictions for each CVE.
- `parse_class.py`: Implements semantic role labeling (SRL) extraction using AllenNLP.
- `nlp_general.py`: NLP utilities for sentence splitting, lemmatization, and SRL post-processing.
- `requirements.txt`: Python dependencies for SMET
- `id2ATT&CK_V2.json`: Mapping from classifier output indices to ATT&CK technique IDs.
- `LR_ATT&CK_model_V2.pkl`: Pre-trained logistic regression model for ATT&CK classification.
- `id2mitre.json`: Mapping from ATT&CK IDs to their full MITRE names.

## Setup
Activate the environment installed for SMET.

Download and install the spaCy English model:

`python -m spacy download en_core_web_lg`
## Usage


### Running SMET Mapping
To run the SMET mapping over the project's train or test set, run: `python 
run_smet.py` from this directory. 

By default, SPLIT = "train" is set in run_smet.py. Change this variable to "test" to process the test set.
Output predictions are saved as a timestamped JSON file in 
`models/uncategorized_mapping/SMET_output/`

#### Output Format
Each entry in the output JSON contains:
target_cve: The CVE ID
predictions: List of predicted ATT&CK technique IDs (ranked by confidence)
confidence: Corresponding confidence scores

## Notes

SMET is used as an external baseline for the main approach, TRIAGE.
To compare SMET predictions with TRIAGE, use the output files generated by run_smet.py.
